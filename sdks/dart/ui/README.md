# vision_agents_ui

Flutter widgets for a conversation with a Stream Vision Agent: the transcript, what the agent is
doing, somewhere to type, and a conversation kept in Stream Chat.

```dart
ConversationView(session: await agents.agent('support').chat())
```

See [the Dart SDKs](https://github.com/GetStream/Vision-Agents/tree/main/sdks/dart) for the rest.
