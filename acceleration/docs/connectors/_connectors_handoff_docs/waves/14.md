# Wave 14: G1 fallback — a router-hosted egress proxy, provider-independent, behind the same CredentialBroker

base: wave 13's deployed tag (recheck at entry)   after: wave 13 tag   tag: provisional   status: planning
brief: <scratchpad>/waves/g1-brief.md
linear: parent AI-1572

Why (Kanat 2026-10-20): a fallback if we change sandbox provider, or if a provider has no
credential brokering. This is Tommaso's design taken literally: the token never leaves the
router; the proxy resolves it per request.

Planner rulings:
- P6 Transport: Daytona `OutboundProxyUrl` (sdk-go types.go:118-121) sets HTTP(S)_PROXY in the sandbox; `DomainAllowList` = the proxy host only, so the network layer forces every request through it («combine with DomainAllowList for network-layer enforcement», same comment). Any other provider needs only «env vars + an egress allowlist», the least a sandbox offers.
- P7 Identity (Tommaso's layer 2): one random proxy credential per sandbox, in the proxy URL (`http://sbx:<cred>@proxy…`, sent as `Proxy-Authorization`), stored as SHA-256 in Redis → {session id, grants} with the session's TTL. Any router replica can serve a request, because grants and `core.Resolver` are shared (Postgres + Redis). Deleted on Close.
- P8 TLS: CONNECT to a host outside the grants → refused (403), not tunnelled. CONNECT to a granted host → the proxy terminates TLS with a leaf from a router CA (key from config, like `ROUTER_AUTH_KEK`), re-originates TLS to the real host with system roots. The CA cert (public part only) is written into the sandbox and named by `SSL_CERT_FILE`, `REQUESTS_CA_BUNDLE`, `NODE_EXTRA_CA_CERTS`, `GIT_SSL_CAINFO`.
- P9 Substitution: only in `Authorization` (`Bearer <ph>`, `token <ph>`, Basic whose password is `<ph>`), only when the request's Host equals the CONNECT target and both are granted; never in body or query (v0 lesson); responses rewritten token → placeholder. The token comes from `core.Resolver.Resolve` per request (no copy anywhere, revocation immediate). Basic support means git works through this broker without the Bearer trick.
- P10 Port: `ROUTER_SANDBOX_PROXY_ADDR`, default off; staging `:8090` (no default router port uses it: config.go:415 `:8080`; compose.yaml 55432/56379/8080/3000; recheck at entry). Exposing it on staging is an infra change: human gate.
