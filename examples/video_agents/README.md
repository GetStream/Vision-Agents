# Video agents

Agents that watch as well as listen.

- [flower_spotter](flower_spotter/): an iOS camera on a call, Roboflow detection on the video, voice from the router.

- [security_camera](security_camera/): a door camera that announces arrivals and packages, names enrolled faces and logs who picked a package up, on the router's detection.

- [describe_image](describe_image/): direct image inference through the `vlm` alias.
